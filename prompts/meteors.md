## Build an “Asteroids” Multiplication Game
Create a game where the player practices multiplication by selecting falling asteroids that show the correct answer.
Gameplay
- Place a rocket near the bottom of the screen, with an animated flame that makes it look like it is flying.
- Have 10 asteroids fall from the top of the screen. Display a number inside each asteroid.
- Show a multiplication problem near the rocket. The correct answer should match the number on one of the asteroids.
- The player selects an asteroid by clicking or tapping it.
- If the selected asteroid is correct, remove it from the screen.
- If the answer is incorrect, subtract one life.
- When the player runs out of lives, make the asteroids speed up and crash into the rocket, ending the game.
Assets and statistics
- Use the asteroid_1, asteroid_2, and asteroid_3 images, chosen at random for the asteroids.
- Record the player’s answers in the same statistics system used by the other games.
Follow the existing project’s design, controls, and conventions when implementing the game.
